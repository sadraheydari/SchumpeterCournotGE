# SchumpeterCournotGE

A Julia implementation of a Schumpeterian endogenous growth model with heterogeneous Cournot competition in a continuum of industries.

The model combines dynamic R&D investment, endogenous innovation, firm heterogeneity, endogenous entry and exit, and general equilibrium. Industries interact through aggregate wages, demand, and the evolving cross-sectional distribution of firm productivity.

This repository contains the numerical implementation used to solve the model and generate the quantitative results.
